# Q1 时间线因果推理（7跳）

2026年第二季度，明创工坊的明星产品"AI代码助手插件"季度收入从12.8万元降至9.1万元，下降29%。请按时间顺序列出Q2期间与该产品收入下降相关的全部变更事件，并说明每个事件与收入下降的因果关系。注意：相关线索分散在Excel（含隐藏的备注列）、Word、PDF、PPT等多种文档中，且该产品在不同文档中使用不同名称。

## 1. 结论
Q2内与收入下降相关的变更共有4项，按材料可确定的时间顺序为：

1. **5月6日：Cursor升级至v2**  
   API签名、AST解析和补全触发机制均发生变化，导致插件代码分析模块失效、实时代码补全完全不可用、语法检查误报率升至35%，直接损害用户体验并降低续费意愿。

2. **5月6日至5月20日：插件适配修复**  
   修复期间无法正常发布更新，已购用户只能使用兼容v1但不兼容v2的旧版本，持续造成使用中断和用户流失。

3. **同期（Cursor v2故障及适配期间）：GitHub Copilot免费额度由每月50次增至200次**  
   竞品免费额度扩大，使部分用户在插件不可用期间转向Copilot，进一步加剧用户流失。

4. **Q2内（具体日期未在证据中明确）：订阅制/定价调整**  
   该调整被材料列为收入下降因素，贡献约**-17个百分点**；Cursor v2兼容性问题贡献约**-12个百分点**，共同造成收入从3月的12.8万元降至6月的9.1万元，降幅约29%。Excel还显示，同期付费用户由261人降至186人、月流失用户由4人增至39人，续费率由85%降至63%。

## 2. 推理路径
产品身份先完成跨格式对齐：  
**AI代码助手插件 = code-assist-pro = 代码助手 = 代码助手插件P03 = 智能编程插件**（来源：测试集A_产品规格与定价文档.pdf，第15页表2；测试集A_工作室运营手册.docx，第6节“产品名称对照表”表2）。

- **2026年5月6日：Cursor v1→v2**  
  **Cursor v2升级** → **completionProvider更名为inlineCompletionProvider、参数结构调整、AST格式和补全机制变化** → **code-assist-pro代码分析模块失效、实时代码补全不可用、语法误报率升至35%**（来源：测试集A_工作室运营手册.docx，第3.2节“产品兼容性与更新”，第24—39段）  
  Excel备注进一步记录“v2升级导致P03兼容性问题和插件稳定性下降”（来源：测试集A_运营数据记录.xlsx，“AI工具使用统计”Sheet，H9）。

- **2026年5月6日至5月20日：适配与恢复**  
  **适配工作启动** → **无法正常发布更新** → **已购用户继续使用不兼容v2的旧版本** → **用户体验受损、续费意愿下降**（来源：测试集A_工作室运营手册.docx，第3.2节“产品兼容性与更新”，第24—39段）。

- **2026年5月6日至5月20日期间：竞品替代**  
  **Copilot免费额度由50次/月增至200次/月** → **用户在code-assist-pro不可用期间转向免费竞品** → **code-assist-pro用户流失加剧**（来源：测试集A_工作室运营手册.docx，第3.2节“产品兼容性与更新”，第24—39段）。

- **Q2内：订阅制/定价调整**  
  **订阅制/定价调整** → **收入下降贡献约17个百分点**（来源：测试集A_工作室运营手册.docx，第2.1节“定价策略与AB实验”，第9—19段；测试集A_产品规格与定价文档.pdf，第5页）  
  **Cursor v2兼容性问题** → **收入下降贡献约12个百分点**（来源：测试集A_工作室运营手册.docx，第2.1节“定价策略与AB实验”，第9—19段）。

- **收入结果核对**  
  **2026年3月收入12.8万元** → **2026年6月收入9.1万元**，减少3.7万元，约下降29%；同时付费用户261人降至186人、流失用户4人增至39人、续费率85%降至63%（来源：测试集A_运营数据记录.xlsx，“收入与续费率统计”Sheet，C13、I13；C19、I19）。PPT对6月1日Q2收入确认的总结为“12.8万元降至9.1万元”（来源：测试集A_产品运营分析报告.pptx，第2页）。

## 3. 不确定项
材料能够确定Cursor v2升级发生在5月6日、适配完成于5月20日，但**未提供Copilot免费额度调整和订阅制/定价调整的具体日期**；因此后两项只能确定发生在相关故障期间或Q2内，无法进一步精确到日。
